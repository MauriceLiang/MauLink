# MauLink 0.1.1-rc.20 macOS 测试包

适用于 Apple silicon（arm64）的本机测试构建：

- [DMG 安装包](MauLink_0.1.1-rc.20_aarch64.dmg)：打开镜像后，将 `MauLink.app` 拖入“应用程序”。
