# MauLink 0.1.1-rc.16 macOS 测试包

适用于 Apple silicon（aarch64）的本机测试构建：

- [DMG 安装包](MauLink_0.1.1-rc.16_aarch64.dmg)：打开镜像后，将 `MauLink.app` 拖入“应用程序”。
- [ZIP 应用包](MauLink_0.1.1-rc.16_aarch64.zip)：解压后将 `MauLink.app` 拖入“应用程序”。

应用使用 macOS ad-hoc 签名，未使用 Developer ID 签名，也未经 Apple 公证。首次打开时，Gatekeeper 可能显示安全提示。
