# MauLink 0.1.1-rc.18 macOS 测试包

适用于 Apple silicon（aarch64）的本机测试构建：

- [DMG 安装包](MauLink_0.1.1-rc.18_aarch64.dmg)：打开镜像后，将 `MauLink.app` 拖入“应用程序”。
